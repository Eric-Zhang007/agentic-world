# GTA 参考记忆训练数据集

本包是完整统一交付，无需任何旧压缩包。包含全部 6,971 条合格任务记录、媒体、相机/世界状态、累计训练清单、读取代码和审核材料。所有样本位于同一个 samples 目录。

## 数据范围

| 任务 | 数量 |
| --- | ---: |
| 场景背景参考 | 1,987 |
| 人物参考 | 3,539 |
| 车辆参考 | 1,191 |
| 混合物体参考 | 254 |

这些记录对应 6,062 个不同目标视频窗口，其中 909 个窗口被物体任务和背景任务分别使用。不能将任务记录数当作独立视频数量。

背景样本以先前 RGB/白模帧对为参考，以后续白模视频为条件，以同步 RGB 视频为监督。不要求 object 对应。物体样本保留 object 与参考帧的关系及辅助掩码。两类任务统一交付，但训练时须按 task 解释，不能假定每条样本都有物体身份标签。

## 开始读取

解压整个包，进入解压目录：

```bash
pip install -r requirements.txt
python example.py
```

```python
from dataset import load_dataset
dataset = load_dataset('/path/to/unpacked_dataset', 'train_round_00', [0,30,60,90,119])
sample = dataset[0]
conditions = sample['conditions']
supervision = sample['supervision']
```

不传 temporal_indices 时读取全部 120 帧，内存占用更大。读取器返回 NumPy 数组，不包含模型特定的缩放、VAE 编码或 batch collate；按实际训练接口处理。对象参考数量可变，不应直接用默认堆叠处理所有字段。

## 清单和配比

manifests/train.jsonl、validation.jsonl、test.jsonl 是完整样本池。10 个 train_round_XX.jsonl 提供背景 50%、人物 20%、车辆 20%、混合物体 10% 的均衡采样起点。每轮 2,440 条，轮内任务记录不重复，轮间会复用；附近连续历史最多占背景部分一半，并按位置/实例分组采样。比例没有经过模型训练验证。

累计背景含跨相机经过 745 条、同相机返回 206 条、附近历史 1,036 条。附近历史不等于长期重访，跨相机也不必然是长期重访。完整池与各轮清单是两种取样方式，不要将它们拼接造成重复。拆分按 episode 隔离，不保证 GTA 地图位置互斥。

## 质量与限制

已完成清洗、时序配对、导出解码检查、抽帧视觉审核、实际读取验证及统一压缩包完整性校验。视觉验收不是每帧精查；旧背景参考和本次新增背景参考的审核范围不同，见 provenance 下原始报告。物体标签不是全场景穷尽标注，建筑/地面实例记忆、外观变化事件和长期记忆更新未完整实现。白模沿用粗几何，掩码为模型估计，少量 HUD 可能残留。不能把有效像素掩码视为完整 HUD 分割。

这是已清洗且可读取的训练候选集，尚未验证师姐的模型接口、LoRA/全参训练配置或训练效果。本包没有权重，没有启动模型训练，也不规定必须使用 LoRA。建议先运行示例，再按 DATA_FORMAT.md 接条件与监督，进行小批量训练验收。

## 文件导航

- DATA_FORMAT.md：样本及读取输出说明。
- DATASET_REPORT.json：统一数量与 split 统计。
- VERIFICATION.json：本包完整性和解压后读取验证。
- samples/：全部样本媒体与状态文件。
- manifests/：完整划分和均衡采样清单。
- provenance/：历史清洗报告、剔除记录、处理代码等审计材料；其中的旧路径和旧计数仅描述当时批次，不是当前入口。
