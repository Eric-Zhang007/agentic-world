# GTA 记忆数据验收小包

这是完整交付数据的验收子集，不需要下载大包即可读取。背景/人物/车辆/混合物体按 50%/20%/20%/10% 选取，精确数量、场景来源与审核结果见 REPORT.json。全部来自训练划分，不是独立测试集；用于检查数据格式、配对、视觉质量和模型接口。

```bash
pip install -r requirements.txt
python example.py
```

样本完整保留历史 RGB/白模参考帧、120 帧目标白模与 RGB 视频、原有相机/世界状态及对应关系。manifests/acceptance.jsonl 为唯一入口，samples/ 为统一根目录。条件与监督字段见 DATA_FORMAT.md。运行示例默认取五帧；不指定 temporal_indices 则读取完整片段。

请重点验收：参考帧是否指向同一场景/对象；白模和 RGB 是否时序、相机大致对齐；背景纹理是否有可用参考；输入与监督是否正确区分；task 与物体关系是否被训练代码正确解析。样本内的 qa 图或 comparison/video_review 图可辅助目视检查。

选样使用固定种子，按 episode、背景关系及位置/实例分散取样，不按最漂亮的结果挑选。视频没有为控制体积裁短。附近历史不是长期重访；物体关系不是穷尽场景标注。原始粗几何、抽帧审核和可能残留 HUD 等限制仍然适用。没有运行模型训练，不保证训练效果。
