# GTA 源数据接入

以 [恢复与重建记录](gta555_full_rebuild_plan.md) 和实际状态文件为准。

此前文档把 30 个本地分片描述成完整源包，结论错误。2026-10-26 解包和逐文件检查后，
确认缺少大量 RGB、JSONL 和 spool。当前正在从旧目录及原 OSS 源补齐。
历史索引中的 21 个 episode、42 路视角、1,992 段是目标范围，不是新数据已经验收的数量。

可接入的信息包括实际相机、动作、动态世界状态、时钟与 PTS、静态碰撞几何和材质、
冻结的渲染输入及原编译器。这些是源数据记录；是否在某帧中可见仍需投影与遮挡判断。

既有 `GTA_memory_training_unified.zip` 和不到 1GB 的验收包保持不变。
新源数据用于补全上游重建与采样，不能因文件下载成功就宣称新训练集已通过审核。
